💻 Guia de Execução: Isolada ou Unificada

Ambos os sistemas foram construídos para operar de maneira 100% modular, sem dependência mútua obrigatória.

1. Executar os Dois Sistemas Juntos (Portal Unificado) 
# A partir da pasta portal_geociencias:
cd "D:\Pedro\Desktop\portal_geociencias"
python portal_app.py

# Acesso Unificado no Navegador:
# Hub:         http://localhost:8000/
# Títulos:     http://localhost:8000/titulos
# Lineamentos: http://localhost:8000/lineamentos
2. Executar Apenas Títulos Minerários 
# A partir da pasta do Tema 1:
cd "D:\Pedro\Desktop\Sistema corporativo de gestão de títulos minerários\gestao_titulos_anm"
python app.py

# Ou dentro do portal:
# cd "D:\Pedro\Desktop\portal_geociencias	itulos" && python app.py
# Acesso: http://localhost:8080/
3. Executar Apenas Lineamentos Estruturais 
# A partir da pasta do Projeto 4:
cd "D:\Pedro\Desktop\Extração de lineamentos estruturais\extracao_lineamentos"
python app.py

# Ou dentro do portal:
# cd "D:\Pedro\Desktop\portal_geociencias\lineamentos" && python app.py
# Acesso: http://localhost:8081/
4. Publicação Gratuita na Nuvem (Render / Railway / Fly.io) 
# Nenhuma dependência pesada! Comando de Start:
python portal_app.py

# Variáveis de Ambiente Suportadas:
PORT=8000
DATABASE_URL=postgresql://usuario:senha@host:5432/banco
# Zero senhas fixas no código!
